# 2026-10-29

## 统一博客文章 frontmatter 格式

- 项目实际是 Vue 3 + Vite 静态博客，文章位于 `Myblog/content/posts/*.md`，由 `Myblog/plugins/markdown-posts.js` 通过 gray-matter 解析，生成虚拟模块 `virtual:posts`。
- 插件强制校验：`title`(string)、`date`(string，必须被引号包裹且形如 YYYY-MM-DD)、`description`(string)、`tags`(string[])，否则构建直接抛错。
- 统一后的唯一标准头部字段：`title` / `date` / `description` / `tags`，tags 用行内数组写法，日期一律加双引号（不加引号会被 YAML 解析成 Date 对象导致校验失败）。
- 已处理 5 篇文章：sort.md、hot-deploy.md 原用 `published`，ThreadLocal.md 原带 UTF-8 BOM 且用 `published`+`draft`，es.md 用块状 tags，mysql.md 完全没有 frontmatter（补写标题/日期 2026-09-25/摘要/标签）。
- 一并移除未被任何代码使用的字段：`published`、`updated`、`pinned`、`image`、`category`、`draft`。
- `npm run build` 已验证通过。
- 遗留问题（未处理）：mysql.md 正文是未排版的流水笔记，图片使用 `![alt text]` 占位 alt，且引用的是 `content/posts` 下的本地 png，不在 `public/` 资源路径内。
